🚀 How to use ABYSS

Four steps from query to genome download — no installation, no account, no limits.

1

Browse a module

Pick a typing view (MLST, Capsule), gene-based retrieval (AMR, Virulence, Plasmid), or the Master Table for everything at once.

2

Stack filters

Combine genotype + geography: e.g. IC2 + KL2 + OXA-23 + Ghana + blood + 2015–2023.

3

Export accessions

Click 🧬 Accessions to download a plain-text list of matching genome accession IDs — one per line.

4

Download genomes

Feed the list to NCBI: datasets download genome accession --inputfile list.txt — that's it.
