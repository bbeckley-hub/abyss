📖 How to use these files

Every file is a gzipped TSV. Decompress and open with pandas, R, or the command line:

gunzip mlst_all.tsv.gz
head -5 mlst_all.tsv

Or read directly from Python without decompressing — pandas handles .gz automatically:

import pandas as pd

mlst  = pd.read_csv("mlst_all.tsv.gz",    sep="\t")
caps  = pd.read_csv("capsule_all.tsv.gz", sep="\t")
meta  = pd.read_csv("abyss_metadata.tsv.gz", sep="\t")

# Join typing + capsule + metadata on accession
df = (mlst.merge(caps, on="accession", how="left")
          .merge(meta, on="accession", how="left"))

# IC2 genomes with OXA-23 from bloodstream infections
df[(df["IC"] == "IC2") & (df["source"] == "blood")].head()

🧬 Long-format gene tables

amr_all.tsv, vfdb_all.tsv, and plasmid_all.tsv are in long format — one row per (accession, gene) presence. To pivot to a wide presence/absence matrix: 

amr_wide = (amr.assign(present=1)
               .pivot_table(index="accession", columns="gene",
                            values="present", fill_value=0))

🔗 GCA ↔ GCF translation

Metadata is GCF-preferred; gene tables are GCA-keyed. All joins in this dataset use the numeric accession stem, so they work as-is. If you need to map between NCBI pairs explicitly, use AB_59160.tsv from the ABYSS repository.
